# 🚀 Project Name – Investment & Casino Platform

A **next-generation financial and gaming platform** built with **CodeIgniter 4**, combining  
**MLM referral systems, secure investment management, and casino gaming modules** in a single scalable ecosystem.

This platform is designed for **high-traffic, real-money applications** with strong security, modular architecture, and future-ready extensibility.

---

## 🌐 Core Modules Overview

### 🔗 MLM (Multi-Level Marketing) System
A powerful and flexible MLM engine supporting multiple business models:

- Multi-level referral & downline tracking  
- Binary / Matrix / Unilevel plan support  
- Automatic commission & bonus calculation  
- Rank & reward management  
- Real-time wallet & balance updates  

---

### 💰 Investment Management System
A complete investment solution with automated profit handling:

- Multiple investment plans & packages  
- ROI calculation (daily / weekly / monthly)  
- Auto profit distribution system  
- Capital lock & maturity handling  
- Detailed investment history & reports  

---

### 🎰 Casino Gaming Module
A secure and fair casino gaming system fully integrated with user wallets:

- Slot, Dice, Card & Instant games support  
- Real-time bet & balance processing  
- Provably fair result handling  
- Game profit & loss tracking  
- Complete bet & game history  

> Casino module is fully wallet-driven and connected with the MLM & Investment balance system.

---

## 👤 User & Account Management
